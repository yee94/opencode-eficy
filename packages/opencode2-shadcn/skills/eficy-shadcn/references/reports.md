# 数据分析与报告

用户要求数据分析、图表解读或报告时，直接生成 `.eficy` 报告并返回可打开的链接。shadcn、图标和图表按主 skill 的固定版本 HTTPS 地址导入。

1. 确定分析问题、数据来源、时间范围和统计口径。用户给了数据就据此计算；演示数据明确标注。
2. 可调用 `eficy_shadcn_template({ preset: "analytics" })` 获取经营分析报告，或 `preset: "operations"` 获取履约分析报告。工具只返回 TSX；替换为当前问题对应的数据和结论。
3. 按「标题与范围 → 核心结论 → 关键指标 → 趋势/构成图 → 必要明细 → 数据口径与局限」组织内容。按问题选择图表，不强制堆满图表或管理控件。
4. 结论、指标和图表使用一致口径，筛选后同步更新；抽样明细注明与汇总的关系。区分事实、解释和建议，相关性不直接写成因果。
5. 使用主 skill 的校验与保存流程，浏览器检查 400px、600px 和宽屏居中效果，包括筛选、Tooltip 和空结果。

## 暗色阅读主题

- 近黑背景、深灰卡片、细灰边框与亮色正文；蓝色主序列、青色辅助序列，状态同时提供文字。
- 阅读宽度目标 400–600px：根容器 `width:100%; max-width:600px; margin-inline:auto; box-sizing:border-box`，内边距 16–20px。小于 400px 随容器收缩，宽屏保持 600px 居中。
- 正文 14–16px、行高 1.7–1.85；标题 24–28px、结论小标题 18px。
- 图表单列、KPI 最多两列；日期与维度筛选靠近标题。核心结论无需横滚即可读完，宽明细表只在自身容器内横滚。
