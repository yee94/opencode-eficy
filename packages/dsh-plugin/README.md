# [Eficy](https://github.com/yee94/Eficy) for DeepSeek Harness

Eficy 为 DeepSeek Harness 提供基于 React 组件生态的单文件页面创作与预览。预置 shadcn、Lucide 和 Recharts 的使用支持，配合 Tailwind 样式和设计指导，用于生成布局、样式和交互较完整的报告、看板及小工具。

## 特性

### 内置组件支持

| 组件库 | 用途 |
| --- | --- |
| shadcn | 按钮、表单、卡片、表格、标签页等界面组件 |
| Lucide | 风格统一的图标 |
| Recharts | 折线图、柱状图、饼图等数据图表，以及提示和图例 |

助手可以直接组合这些组件完成页面，不必逐个编写基础控件、绘制图标或实现图表。

### 设计指导

随插件提供布局、信息层级、主题、图表选择和响应式排版的指导。报告按结论、关键指标、图表和明细组织，并提供经营分析、履约分析模板作为起点。具体布局和风格可以按需求调整。

### React 生态与 Tailwind 样式复用

除预置组件外，也可以直接使用兼容浏览器加载的 React 生态组件，无需为每份页面单独搭建项目或手动编译、打包。样式支持 Tailwind 常用工具类写法，可复用现有的间距、颜色、布局和响应式样式。

### 面向成品的单文件产物

内容、数据、组件和交互保存在一个文件中。生成目标是一份具有完整布局、统一样式和必要交互的页面，例如可筛选的分析报告、能调整参数的预算工具，而不只是基础标签的组合。

文件可以在会话中直接预览、继续修改，也可以导出为文档、长图或交互网页。

## 与 Markdown、HTML 的区别

| 能力 | Markdown | 原生 HTML | Eficy |
| --- | --- | --- | --- |
| 内容基础 | 文字、表格、图片 | 页面标签和基础表单元素 | React 组件、数据和交互 |
| 界面、图标与图表 | 通常依赖阅读器扩展或图片 | 需要自行实现或接入组件库 | 已提供 shadcn、Lucide、Recharts 支持 |
| React 组件复用 | 基础格式不提供 | 需要另外接入运行环境及组件 | 可直接使用兼容的 React 组件 |
| 样式 | 主要由阅读器主题决定 | 自行编写样式或接入样式框架 | 支持 Tailwind 常用工具类与组件主题 |
| 设计约定 | 格式本身不提供 | 格式本身不提供 | 配套设计指导和报告模板 |
| 典型产物 | 以阅读为主的文档 | 完成度取决于自行组织的页面实现 | 面向直接使用的交互报告、看板和小工具 |

原生 HTML 本身不包含这些组件库、React 运行环境、Tailwind 样式支持和设计约定。使用 HTML 制作相同页面时，需要另行接入这些能力；Eficy 已经把它们作为创作基础提供给助手。这是它与普通 HTML 预览的主要区别。

Markdown 适合说明、笔记和总结。需要较完整的界面、数据展示和交互时，Eficy 可以减少从基础元素开始搭建页面的工作。最终页面仍可导出为 HTML，让未安装插件的人在浏览器中使用。

## 使用

向助手提供数据和需求，例如：

> 用 Eficy 把这份销售数据做成月度报告，展示主要结论、销售额、增长趋势和渠道表现，支持按地区筛选。

生成后点击预览链接，在右侧查看和操作页面。需要调整时继续描述修改要求，例如“增加按月份筛选”或“把渠道占比改成柱状图”。没有实际数据时，可以要求使用并标注演示数据。

## 导出

点击预览右上角的下载图标，选择格式：

| 格式 | 用途 | 保存内容 |
| --- | --- | --- |
| PDF | 阅读、存档或打印 | 当前页面的分页图片，保留筛选结果；文字不能选中复制 |
| PNG | 分享完整长图 | 当前页面及筛选结果 |
| HTML | 在浏览器中继续操作 | 保留交互功能，从页面的初始数据和条件开始运行 |

HTML 导出不保存当前临时输入或筛选状态。需要指定默认条件时，请让助手修改页面的初始设置。部分组件、图片和字体需要联网加载。
