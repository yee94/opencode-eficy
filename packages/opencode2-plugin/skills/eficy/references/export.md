# HTML 导出方法

用户要求 HTML 时，由 agent 生成实际的 `.html` 文件并返回文件链接。此流程只需要本 skill 目录和 Node.js 22+，不依赖插件安装、预览界面或宿主 API。

## 执行

1. 准备页面的完整 `.eficy` TSX 源文件；新建页面按主 skill 的组件与报告规范编写。已有页面直接使用其源码。用户要求保留某些筛选或输入值时，先将这些值写入导出用源码的初始数据。
2. 执行 skill 自带的脚本。将 `<skill目录>` 替换为本 SKILL.md 所在目录，输入与输出使用实际路径：

   ```sh
   node "<skill目录>/scripts/export-html.mjs" "/绝对路径/report.eficy" "/绝对路径/report.html" --title "分析报告" --theme dark
   ```

   `--title` 默认取输入文件名，`--theme` 支持 `dark`（默认）或 `light`。脚本先校验后写入；校验失败按错误修正源文件后重试，无需 `eficy_validate` 工具。目标目录须已存在，已有输出文件会被覆盖。
3. 在浏览器打开生成的 HTML，检查正文、图表、输入绑定和事件；外部资源加载失败时修正源码中的 URL 后重新导出。没有浏览器能力时如实说明只完成生成与静态校验。
4. 返回实际输出的 `[下载 HTML](report.html)` 链接。完成标准是文件已生成，而不是告知用户去菜单点击导出。

## 与预览导出相同的机制

脚本和预览的「导出 HTML」共用文档生成器：将源码、Eficy/React 运行时、编译器与启动逻辑内嵌进完整 HTML。打开后自动编译 TSX 和工具类、加载组件样式并挂载默认导出；Signals、computed、输入绑定和事件继续工作。标题和源码按 HTML/script 边界转义，主题由导出参数指定。

HTML 从源码初始状态启动，不序列化正在运行的 Signal 值。HTTPS 模块、CSS、图片和字体保持原 URL，因此单文件不等于完全离线；只有全部资源均已内嵌的页面才可离线运行。独立页面不注册宿主消息及本地文件跳转转发，重试直接刷新文档。

## 独立分发

复制 skill 时保留整个目录，包括 `scripts/export-html.mjs`。该脚本已打包所需校验器、文档生成器和运行时，执行时无需安装 npm 依赖或访问原项目源码。脚本由项目构建从共用实现生成；更新实现后重新构建并分发整个 skill，保持两种导出入口一致。
